# QR 循环与单张显示尺寸优化设计

## 目标

降低循环播放和单张显示时的默认二维码视觉尺寸，并允许用户即时调节。网格平铺和全屏查看保持现有行为，二维码载荷、纠错级别和 V2 协议不变。

## 现状与问题

- 私有二维码通常以 200px 生成，公有二维码以 300px 生成。
- 循环模式对整个 `.qr-item` 再应用 `scale(1.5)`，公有二维码最终可达到约 450px。
- 单张模式直接沿用生成时的像素尺寸，没有独立、统一的显示尺寸设置。
- 二维码生成尺寸与显示尺寸耦合，导致不同协议类型在相同模式下视觉大小不一致。

## 交互设计

在“显示模式”区域增加一个“二维码尺寸”控制，仅当模式为“循环播放”或“单张显示”时显示：

- 控件：原生 `range` 滑杆。
- 范围：160–360px。
- 步进：20px。
- 默认值：220px。
- 当前值：在滑杆旁实时显示，例如 `220px`。
- 循环播放和单张显示共用同一个值。
- 用户调整后立即更新当前显示，不重新生成 QR 数据。
- 使用 `localStorage` 保存最后一次选择；保存值损坏、越界或无法读取时回退到 220px。

网格平铺不显示该控件，也不受该值影响。进入全屏查看时继续按视口自适应，不受 160–360px 设置限制。

## 实现方式

### 显示与生成解耦

保留 QRCode.js 当前生成结果，不为每次滑杆变化重新编码。通过 CSS 自定义属性控制循环和单张容器内的二维码画布、图片或 SVG 的可视宽高：

```css
#qrDisplay.loop-mode .qr-item > div:first-child,
#qrDisplay.single-mode .qr-item > div:first-child {
    width: var(--display-qr-size);
    height: var(--display-qr-size);
}
```

具体选择器必须同时覆盖 QRCode.js 可能生成的 `canvas`、`img` 和 `svg`，并保持 1:1 比例。移除循环模式的 `transform: scale(1.5)`，避免标签、卡片留白和按钮一起被放大。

### JavaScript 状态

新增单一状态值 `displayQRSize`：

- 初始化时从 `qr_display_size` 读取并校验。
- `setDisplayQRSize(value)` 负责截断到 160–360、对齐 20px 步进、更新 CSS 变量和数值标签，并尝试写入 `localStorage`。
- `setMode()` 负责控制尺寸设置区域的可见性；`loop` 和 `single` 显示，`grid` 隐藏。
- `showQRCode()`、循环换页和指定编号补传不得覆盖尺寸值。
- 语言切换只更新标签文字，不改变数值。

## 响应式约束

- 在窄屏设备上，实际显示宽度不得超过容器可用宽度，使用 `min(var(--display-qr-size), calc(100vw - 80px))` 或等效 CSS。
- 高度与宽度保持一致，不拉伸二维码。
- 标签保持原字号，不随二维码尺寸缩放。
- 220px 默认值应在 iPhone 竖屏、桌面浏览器和分屏窗口中无需横向滚动。

## Safari iOS 下载说明

本次不改变接收端的 Blob + `download` 下载机制。Safari 把文件保存到系统配置的下载位置：通常是“文件”App中的“iCloud Drive/下载项”，用户也可以在“设置 → App → Safari → 下载项”改成“我的 iPhone”或其他位置。网页无法读取或强制指定该目录。

## 测试

新增生产发送端回归测试，至少覆盖：

1. 默认尺寸为 220px。
2. 160、220、360 三个合法值即时生效。
3. 小于 160、大于 360、非数字和损坏的持久化值正确回退或截断。
4. 循环与单张模式共用设置；网格模式不应用该尺寸。
5. 切换 QR 页、暂停/继续、补传和重新生成后尺寸保持。
6. 全屏容器不受普通显示尺寸限制。
7. 移除循环模式 `scale(1.5)` 后，二维码标签和卡片不再被整体放大。
8. 现有 15 项 V2、QR 标准兼容、安全和生产往返测试继续通过。

## 非目标

- 不调整网格平铺二维码尺寸。
- 不改变全屏查看的自适应策略。
- 不改变二维码版本、数据容量、纠错级别、分片数量或扫描协议。
- 不尝试从网页读取或指定 Safari 的真实下载目录。

## 成功标准

- 循环和单张模式初次打开均以 220px 显示。
- 用户可在 160–360px 范围内调节，刷新后保留。
- 公有与私有二维码在同一显示模式下使用一致的可视尺寸。
- 网格与全屏行为无回归。
- 全套自动测试连续运行通过，生产页面无控制台错误。

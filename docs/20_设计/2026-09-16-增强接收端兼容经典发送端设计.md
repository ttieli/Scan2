# 增强接收端兼容经典发送端设计

## 目标

只修改增强接收端，使其默认自动识别增强 RaptorQ、经典 V2 JSON 和当前经典 `Q3F` 文件分片；不修改任何发送端。

## 路由

每个 ZXing 解码结果先按二进制 RaptorQ transport packet 解析。解析失败后，把字节按 UTF-8 文本解码并按以下顺序识别：

1. `Q3F`：经典均匀文件分片。
2. `{v:2,k:t|f,...}`：经典 V2 私有文本或文件。
3. 其他文本：普通二维码文本，直接完成显示。

一次扫描会话只允许一个活动协议，RaptorQ 与经典分片不得混收；重新开始后才能切换。

## 接收体验

- 经典 V2/Q3F 复用增强页面的进度条和最多 200 个进度格。
- 经典模式补扫请求继续输出发送端可直接粘贴的数字范围，例如 `1-3, 7`。
- 完成后沿用增强接收端的文本展示、文件下载和最终 SHA-256 状态。
- RaptorQ 的 `RQ1` 补扫机制保持不变。

## 验收

- V2 私有文本和文件支持乱序、重复、缺片显示和 SHA-256。
- Q3F 文件支持乱序、重复、数字缺片和 SHA-256。
- 增强 RaptorQ 原有测试不回归。
- 两个自包含页面仍无外部运行时引用；经典发送端不修改。
